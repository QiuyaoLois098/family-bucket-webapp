# Vrbo 手机：Figma 核对与缩放说明

设计来源：[当前手机流程](https://www.figma.com/design/VgWnFCqQIZhY2lyWNHS4Yr/Expedia---Vrbo?node-id=3291-3275&m=dev)。只修改手机代码和手机专用素材；原版 main、大屏声明和 Figma 源文件不在本次修改范围。

## 画布与缩放

- 采用实际 frame 数值 **393 × 851.126**，而非 section 名称中四舍五入的 393 × 852。
- 旧 1050 × 2274 按 393/1050 缩小后是 393 × 851.125714，比例本身几乎相同。原网页的主要问题是边框占用内容尺寸、全屏填满任意窗口，以及独立页另行调整上下间距。
- 新版在 `ScaledPhoneCanvas` 中固定内部画布，使用 `scale = min(可用宽度 / 393, 可用高度 / 851.126)` 整体缩放。React 的 ResizeObserver 更新缩放和居中位置；改变窗口不会重新计算内部排版或改变文字换行。
- `/vrbo-ip1`、`/vrbo-ip2`、`/vrbo-ip3` 与 `/vrbo-v2` 使用相同 GuestPhone 和设计画布。外部姓名标签、测试机身不计入内容比例。不同宽高比的窗口留边，不拉伸。
- 多屏版显示模拟 Dynamic Island／Home Indicator；独立手机页保留相同内容坐标，隐藏模拟硬件标记，以使用设备自身的硬件与系统指示条。

## 布局及素材修正

- 统一页头位置、身份行、成员标签、姓名页头像／说明／输入框／Continue 的尺寸与间距。输入框 247.029 × 38.926，Continue 168.429 × 51.651。
- 选择网格使用 163.189 × 69.627 的卡片、12.726 的列间距及 21.709 的行间距；提示与消息草稿按设计槽位排列。
- 聊天气泡宽 309.235、圆角 15.72，作者与正文分别使用 Medium／Book。保留现有消息动画和动态强调规则。
- 最终页采用手机专用的 343.594 × 111.911 分享卡，修正照片、评分、价格和分享出处位置；按可见 Figma 版保留卡片和三位来宾的回复，不额外显示 planner 的过渡提示。
- 最终页头像统一在左侧，自己的气泡仍用蓝色；普通聊天阶段保留自己在右侧的排列。
- 底栏发送图标移至输入框内部。禁用状态仍不能发送；没有增加新的发送行为。
- 8 张偏好卡照片使用 Figma 导出包中的原始 source 照片，避免导出的卡片渲染图把选中态蓝框烘焙进背景。圆角、渐变及蓝框由网页样式控制，勾选标记只随实际选择出现。群头像保留 Figma 的 3x PNG 导出。素材保存在 `public/images/Vrbo-Images/mobile/`，不替换大屏共用素材。
- 选中、发送及收藏图标使用 Figma 返回的原始 SVG，保留文件中的根尺寸及路径。

## 验证

- 构建及差异检查通过。
- 使用同源独立视口承载真实应用页面，通过页面报告和 html.clientWidth/clientHeight 共同确认实际尺寸，避免浏览器窗口工具未应用到后台页造成误判。
- 多屏视口：1280×720、1920×1080、3440×900。独立手机视口：393×852、390×844、430×932。
- 五阶段 × 三个尺寸组合 ×（多屏中的三部手机＋三部独立手机）= **90 个画布样本**。比例检查均通过；可见元素归一到设计坐标后的差异均小于 0.05 设计 px。隐藏层不计入几何比较。
- 五阶段运行时共检查 **258 个文字元素**，字体族、已列出的字号／字重，以及正文与草稿的 ss02 检查通过。
- 原大屏及其他非手机 CSS 声明与修改前逐条比较，未改变。
- 这些结果验证浏览器视口内的渲染；尚未在实体 iPhone 的 Safari／独立 Web App 中完成安全区、键盘和触摸操作验收。
